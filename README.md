# Occluded Foliage

(Alternate name: "Saint's Stunted Growth")

A plugin mod for Fallout: New Vegas that removes foliage growing under objects via raycasting. Divides worldspace into a fine grid, gradually probes every grid cell around the player, and tests for obstructions. If a cell is occupied by a static (e.g. buildings, shacks, walls, trees), grass is eradicated.

Inspired by *No Grass In Objects* that was briefly available for Skyrim pre Anniversary Edition.
